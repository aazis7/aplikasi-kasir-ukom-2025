# Aplikasi Kasir Tunas Pemuda

Aplikasi ini merupakan proyek Ujian Kompetensi Kejuruan Rekayasa Perangkat Lunak
Pada Tahun 2025. Aplikasi berbasis HTML ini mensimulasikan sistem kasir sederhana
yang mencakup pengelolaan data pelanggan, penjualan, detail penjualan, dan
produk.

## Fitur Utama

- **Input Data**
  - Tambah data pelanggan
  - Tambah data penjualan
  - Tambah data detail penjualan
  - Tambah data produk

- **Lihat Data**
  - Menampilkan data pelanggan
  - Menampilkan data penjualan
  - Menampilkan data detail penjualan
  - Menampilkan data produk

- **Navigasi Sederhana**
  - Navigasi antar halaman menggunakan link HTML
  - Tampilan layout terpusat menggunakan tabel

## Teknologi yang Digunakan

- **HTML**: Untuk struktur halaman
- **CSS**: Untuk styling antar muka
- **PHP (tidak di include-kan)**

## Tujuan

- Melatih kemampuan membuat aplikasi web dinamis
- Memahami struktur halaman HTML
- Menunjukkan kemampuan dalam membuat layout, form input, dan navigasi

## Lisensi

Proyek ini dibuat untuk keperluan pembelajaran dan Ujian Kompetensi Kejuruan. Hak cipta oleh RPL 2025.
